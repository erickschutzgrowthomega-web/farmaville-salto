# Farma Ville Landing Page

Crie uma Landing Page profissional, moderna, responsiva e otimizada para conversão para a Farmácia Farma Ville, localizada em Salto, São Paulo.

OBJETIVO PRINCIPAL:
A página será utilizada como destino de campanhas do Google Ads. O principal objetivo é apresentar a Farma Ville, transmitir confiança e facilitar o contato do usuário pelo WhatsApp.

A conversão principal da página deve ser o clique no WhatsApp.

DIRETRIZES VISUAIS:

- Design moderno e profissional.
- Visual de saúde/farmácia.
- Passar sensação de confiança, proximidade e praticidade.
- Usar bastante espaço em branco.
- Tipografia extremamente legível.
- Contraste alto.
- Botões de CTA bem destacados.
- Evitar aparência genérica de template.
- Priorizar experiência mobile, pois grande parte do tráfego do Google Ads será pelo celular.
- Não criar excesso de seções.
- Não utilizar pop-ups invasivos.
- Não utilizar carrosséis desnecessários.

PERFORMANCE:

A landing page precisa ser extremamente rápida.

Otimizar imagens.
Evitar bibliotecas pesadas desnecessárias.
Priorizar carregamento rápido em dispositivos móveis.
Usar HTML semântico.
Garantir responsividade perfeita em celular, tablet e desktop.

GOOGLE ADS:

A página será utilizada como URL final de campanhas do Google Ads.

Portanto:
- Não fazer redirecionamento automático para WhatsApp.
- O usuário deve permanecer na landing page.
- O WhatsApp deve ser acionado somente quando o usuário clicar no botão.
- Todos os botões de WhatsApp devem utilizar o mesmo número.
- Não utilizar URLs encurtadas.
- Não criar redirecionamentos externos desnecessários.

SEO LOCAL:

Otimizar a página para pesquisas relacionadas a:

"farmácia em Salto"
"farmácia Salto SP"
"farmácia perto de mim"
"farmácia em Salto São Paulo"
"Farma Ville Salto"
"farmácia delivery Salto"

Criar title e meta description relevantes para SEO local.

IMPORTANTE:
Não invente informações, preços, promoções, horários, medicamentos, serviços, avaliações ou diferenciais que não foram fornecidos neste briefing.

A página deve parecer uma página oficial da Farmácia Farma Ville, e não uma página genérica de anúncio.
